# 屏幕空间追踪阴影方案（设计稿，260912 修订：远景接管）

> **实施后修订（260912 晚，两轮）**：第一轮实测「最远处（shadowDistance 极限）边界渐变描黑」——
> 0.9D→D 环带整体渐变压黑、D 外正常；初诊为远场掠射退化，收紧 `THICKNESS_FAR` 20→10 并加渲染
> 边界淡出。第二轮实机显示边界外**全黑**，定位到真正根因：**两处淡出窗都把可见性直接乘 (1→0)——
> 可见性语义 0 = 全影，乘向 0 是「渐变压黑」（第一轮 bug）、乘到 0 是「全黑」（第二轮 bug），与
> 「淡出效果」的意图（向 1 = lit 收敛）正好相反**；春v2 原版即 `mix(1.0, shadow, fade)` 形式
>（本文 §1.4 记录无误，实现时抄变形）。修复：贴图淡出窗与渲染边界淡出均改 `mix(1, vis, fade)`；
> 第一轮的厚度收紧与边界淡出作为远场掠射退化（径向序对海拔二阶不敏感、命中退化为噪声）的次级
> 防护保留。**教训：对 visibility / 透射率类「1 = 无效果」的量做淡出，永远 mix 向 1、不要乘向 0。**

> 定位约束：低配 / 高兼容、不引入激进渲染特性。结论：**单主光源屏幕空间 ray march，一档追踪
> 兼两职**——近景接触细节补充 + **远景接管**（视距远超 shadowDistance = 128 时，阴影贴图 0.9D→D
> 淡出后屏幕空间阴影成为唯一阴影源）。沿光向对 depthtex1 不透明深度做 ≤8 步世界空间步进、每步
> 透视精确投影、3D 距离窗命中判定；长度 / 起点偏移 / 厚度阈值均随相机距离 remap（0.4→10 格 /
> 0.01→0.1 格 / 0.1→20 格四次曲线，春v2 谱系定档）。**适用范围（春v2 结构、锚点按需求外推）**：
> 近景（< 0.7·D）只 trace 向光非 SSS 像素；远景（≥ 0.7·D）trace 向光**或** SSS 像素，其中 SSS
> 像素的结果在 0.7D→0.9D 与 1.0 线性混合（0.7D 处 = 1.0 无屏幕空间阴影），0.9D 起全效——恰与
> 阴影贴图淡出窗起点衔接。最终与阴影贴图可见性取 **min**（只加暗）。temporalBayer64 抖动起点
> 相位、composite_taa 时间累积收敛。**零新 pass、零新缓冲、零新纹理资产**，每被 trace 像素最多
> +8 次深度 fetch + 8×2 次短矩阵乘（均被 fetch 延迟掩盖）。

## 1. 调研综述

### 1.1 两个流传甚广的误记（先纠正）

- **Complementary 本体没有 "Screen Space Shadows" 选项**。v4 全系、Reimagined r1~r5.9、Unbound
  的 lang 文件与 changelog 均无此项；它唯一的屏幕空间阴影是 r5.8 起针对 Voxy/DH LOD 区块的
  `GetLODShadows`（32 步 × 世界 2.5 格步长、总长约 80 格、固定 5 格厚度带、蓝噪声 + TAA），
  用于替代 LOD 区块没有阴影贴图覆盖的部分。
- **BSL 没有 `SCREENSPACE_SHADOW_NUMBER`**。全版本（v5~v10.1.5）无此 token；它的
  `SHADOW_LOD` 才是屏幕空间阴影（16 步硬编码、世界空间几何级数步长 `2^((i+d)·0.5−2)`、
  累计约 150 格、厚度 4 起每步 +0.5）。`SELF_SHADOW_QUALITY` 是 POM 自阴影步数，不是屏幕
  空间阴影。用户可调步数的 `SCREEN_SPACE_SHADOW_SAMPLES` 滑块出自 **BSL 衍生系**：Komorebi
  （默认 9）、Sundial（默认 12）、**春v2（默认 5）**、iterationRP（12）。

### 1.3 共性结论（设计依据）

1. **全部内联在光照 pass、原地消费**——没有一家为接触阴影落独立缓冲或半分辨率（Complementary
   的 colortex18 是 Voxy LOD 特例）。零新 pass / 缓冲是低配正解。
2. **步数十几步量级**（5~16），靠噪声抖动 + TAA 时间累积补采样密度，**没有一家自带历史缓冲**。
3. **深度图主流 depthtex1**（不透明），Kappa 用 tex0 是特例。
4. **厚度容差随 trace 距离增长**是多数派（Kappa 线性 / BSL LOD 线性 / 春v2 四次 / Sundial
   `0.0005·viewLength`；Photon 固定 10 格是另一档用法）——否则远处必漏影。
5. **出屏即 break**（几乎全体；Bliss 例外靠深度区间兜底）。
6. **合成主流 min**（只加暗不加亮：Bliss / Komorebi / iterationRP / 春v2）；「亮处才 trace」
   早退（春v2）是最便宜的性能门。**远景接管的两种形态**：Photon 距离 fade mix、春v2 / BSL /
   Complementary「贴图淡出 + SS 顶上 + min」——本包取春v2 形态（结构简单、与 min 合成自洽）。
7. 各家公式实现全部自行重写（本方案同样：机制参考共性、公式与代码自研，见 §6 归属声明）。

### 1.4 春v2 调用点结构（本次修订实读 deferred5.glsl，适用范围的直接出处）

```
shadow   = min(parallaxShadow, shadowMapping(...))                    // 阴影贴图（wrap 余弦门控）
shadow   = mix(1, shadow, remap(dist, 0.9D, D, 1, 0))                  // 贴图 0.9D→D 淡出（非硬切）
RTShadow = screenSpaceShadow(viewPos, normal, shadow)                  // 贴图 <0.01 早退；长度/阈值随 dist remap
mixFactor = remap(dist, 0.33D, 0.66D, 1, 0)                            // SSS 抑制窗
RTShadow = remap(dist, 0.9D, D, 1.0, 0.9)                              // D 外整体 ×0.9 微减弱
           * mix(RTShadow, 1, sssWrap·mixFactor·(1−VISIBILITY))        // 近景 SSS → RTShadow 压向 1.0
结果 = min(shadow, RTShadow)                                           // 打包进 gbuffer 供光照 pass 消费
```

即春v2 的「屏幕空间阴影不应用到 SSS 上」= **近景（≤0.33D）SSS 像素的 RTShadow 压向 1.0、
0.33D→0.66D 渐进恢复全效**——近景保住薄叶透光观感，远景（接管区）SSS 像素必须参与 trace，
否则 0.9D 外树冠整体无影。本方案沿用该结构，锚点按需求外推：**分界 0.33D→0.7D、SSS 渐入
0.33→0.66D → 0.7→0.9D**（0.9D 与贴图淡出窗起点重合，交接链自洽）。

## 2. 总体设计决策

### 2.1 作用域：近景接触细节 + 远景接管，一档追踪兼两职

- **近景（< 0.7·D）**：补 `SHADOW_BIAS_NORMAL`（0.05 起、随距离 / 坡度放大）normal offset 与
  PCF 模糊吃掉的接触细节（影子根部悬空、栅栏 / 楼梯棱的小影）——0.4~3 格尺度，屏幕空间信息
  最擅长的区间。
- **远景（≥ 0.7·D，含 D = shadowDistance 之外直到渲染视距）**：视距远超 128 时，贴图 0.9D→D
  淡出后**屏幕空间阴影是唯一阴影源**。远距遮挡者在屏幕上紧邻接收者（世界 10 格的 trace 在
  250 格距离处扫过约 50 像素），大容差厚度窗（20 格）下山体 / 树冠尺度的遮挡可靠命中——
  这是春v2 / BSL LOD 同款作战方式。主 depthtex1 覆盖 MC 渲染的全部几何，无需 DH 深度链。
- 不采 BSL/Complementary 的 80~150 格超长 trace：它们的 LOD 深度分辨率粗、遮挡者远，必须长
  追；本包贴图淡出前 SS 已全程在场（min），淡出窗内接管无缝，10 格封顶足够。

### 2.2 画在哪：`shadeSurface` 内联（deferred_init，光照时序零改动）

- **为什么不独立 composite pass**：composite 在 deferred_init 之后，colortex0 里直射与环境已
  不可分离，事后乘阴影会连环境光一起压暗（夜晚 / 彩色阴影全错）。要干净就得另存直射分量——
  多一张缓冲，违背共性 #1。
- **为什么不是 deferred_init 的 fsh 内联**：pass 文件内不定义函数（AGENTS 约定）。函数进
  `lib/lighting/shadow.glsl`（同域：阴影可见性；依赖 constants / uniforms / space / noise 全在
  其清单上，只新增 `gbufferProjection` 一个 uniform），`shadeSurface` 调用并合成。
- **收益顺延**：`shadeSurface` 是 deferred 与（未来）前向 water 的共享入口，water 接入时自动
  获得；deferred_init 入口文件**零改动**（include 顺序 shadow.glsl → lighting.glsl 已满足）。
- **TAA 之前**：抖动噪声与阴影边缘锯齿由 composite_taa 时间累积抹平，与 PCF 的 temporal
  bayer 同一收敛机制、同一时序位置。

### 2.3 追踪算法（机制春v2 谱系，公式自研重写）

**深度图：depthtex1**（不透明，含手部）。deferred 时刻半透明尚未绘制，tex0 与 tex1 仅差
textured 族粒子深度——粒子不投接触影（运动半透明几何投屏空间影只会闪），与天空判定 /
位置重建取 tex1 同一纪律。

**参数化：世界空间 t 沿光向、端点齐次插值投影**（不预投影两端点插值 *uv/NDC*，也不在 NDC 域
步进）：厚度窗以世界单位（格）表达、语义与分辨率 / FOV 无关；对透视除法**之后**的 uv/NDC 做
线性插值（屏幕域步进）在掠射角有透视失真——但对除法**之前**的 clip 4 维向量插值、每步各自
透视除，矩阵乘对齐次坐标线性、与逐点投影代数恒等（2026-09 修订：初版逐点矩阵乘
`gbufferProjection × vec4(p,1)` 每步 32 FMA 曾认为可被 fetch 延迟完全掩盖，低配卡 warp 在途
数少、依赖 fetch 的 ALU 链实为暴露；两端点 `P·(o,1)` / `P·(stepVec,0)` 出循环后每步仅
4 mad，float64 数值验证机器精度级等价）。

**光向**：`normalize(shadowLightPosition)`（uniform 已声明、视图空间）。它与 `vLightDirection`
同源（vsh 即由它旋转到世界系）、与阴影贴图渲染同一光源——接触阴影补的是贴图判定，用同一
光源才自洽，且免一次世界→视图换算。晨昏切换黑过渡窗口内即便瞬时不一致，直射辐照度双 0、
结果不可见。

**起点**：`origin = viewPos + remap(dist, 5, D, 0.01, 0.1) × (lightDirView + normalView)` ——
沿光向与法向各推一格随距离 remap 的小偏移（春v2 同款配对：与厚度曲线同向增长，近景 0.01 对
0.1 紧窗、远景 0.1 对 20 大窗，自身表面排除的裕度始终充足）。

**步进**：`t_i = (i + dither) × stepLen`，`stepLen = len / SHADOW_SS_STEPS`，世界域均匀步 +
temporalBayer64 起点相位。长度 `len = remapSaturate(dist, 5, D, 0.4, 10)`（D 外饱和 10）：
近景 0.4 格（接触尺度）、远景 10 格（山体尺度）；均匀步随 len 自动缩放——近 trace 步距 5 cm、
远 trace 步距 1.25 格，各自恰好匹配该距离下亚像素化的细节尺度。春v2 用 5 步 + 1.5ⁿ 几何级数
是「少步数覆盖长程」的补偿；本包 8 步下均匀步已达同等覆盖，少一个旋钮。单帧二值命中（命中
即 0、break），软度全部交给 64 相位 × TAA 时间累积——与 PCF 6 tap 低档同一成本纪律，不引入
absorption 累积模型（Sundial 那套留作扩展点）。

**命中判定：3D 距离窗 + 前后序**（春v2 同形，公式重写），每步：

```
z     = textureLod(depthtex1, bufUv, 0).r                       // TAAU 换算见 §2.5
scene = (ndc·projXY, −1) · projD/(2z−1+projC)                    // 视锥常数闭式（典则对称透视矩阵），
                                                                 //   与 screenToView(uv, z) 代数恒等、1 次除
命中 ⇔ length(scene) < length(p)                                 // 场景点比射线点近（前后序，排除自身）
      ∧ dot(scene−p, scene−p) < thickness²(dist)                 // 3D 距离窗（平方形式免 sqrt）
thickness(dist) = remap((dist/D)⁴, x₀, 1, THICKNESS_NEAR, THICKNESS_FAR)
```

- **3D 距离窗而非深度差窗**（本修订关键取舍）：远景接管的主战场是掠射光下山体 / 山脊——射线
  水平绕过遮挡者时深度差趋零、深度窗必漏，3D 距离仍正确度量「射线漂到表面后方多远」。
  代价是每步多一次场景点重建（2026-09 起走视锥常数闭式：`viewZ = −d/(ndcZ+c)` 一次除 +
  `view.xy = ndc.xy·(1/a,1/b)·(−viewZ)`，即下方预留的「正向投影系数解析线性深度」后路的
  执行，免每步第二次 mat4 + 3 div）。
- **四次曲线定档**（0.1→20 格，紧口径保持到 ~0.45D 后陡升）：近 / 中景接触细节要紧窗（否则
  自身薄几何误命中），接管区要大窗（远处表面起伏 + 屏幕域步距透视放大都在数十格量级）——
  四次曲线恰好「中段紧、末段放」，线性 remap 在 0.7D 处已放到 ~9 格、中景误命中不可接受。
- 径向序 `length(scene) < length(p)` 用长度而非 z 轴：与重建坐标同源、免额外分量。

**无效 texel**：每步 `bufUv ∉ [0,1]` break（共性 #5）；`z ≥ 1`（天空）continue；`z <
TAA_HAND_DEPTH`（0.56，常量已在 constants.glsl——**两处消费者、成对维护**）continue——手部
深度经 MC_HAND_DEPTH 重映射、重建失真会伪命中。

**TAAU 域换算**：步骤投影得到全视场 uv（`gbufferProjection` 是全视场 FOV 矩阵），读 buffer
需 `bufUv = uv·S + taaJitterUV()`（TAAU）/ `uv + taaJitterUV()`（原生）——严格是
deferred_init 去抖基底 `uv = (像素uv − vJitter)/S` 的逆运算；`taaJitterUV()` 与 vJitter 逐位
等值（fullscreen_vsh 即如此赋值），函数内部自算、不新增 varying 依赖；重建 scene 同样用全
视场 NDC（与 deferred_init 的 `screenToView(vec3(uv, depth))` 同一去抖纪律；2026-09 起
applyJitter 仿射系数经两端点反解、折叠为 `bufUv = ndc·0.5S + (0.5S + jitter)` 单 mad 链，
唯一真源保持、代数互逆）。**借本效果把 `noise.glsl` 的 `applyJitter` 按 TAAU 补上 ×S**——它本就是为「未来
SSR / SSAO 采样一致性」预留的注释，现写法只在原生档正确。

### 2.4 适用范围、SSS 渐入与合成（调用侧，shadeSurface 内）

```glsl
#ifdef SHADOW_SCREEN_SPACE
// 适用范围（春v2 结构、锚点外推）：近景只 trace 向光非 SSS（保薄叶透光）；远景（接管区）
// 向光或 SSS 都 trace——SSS 像素的结果在 0.7D→0.9D 从 1.0 渐入全效，0.9D 恰为贴图淡出窗
// 起点；背光非 SSS 永不 trace（其 wrap 余弦 = 0、直射本就为 0，纯省成本）
bool nearRange = distWorld < SHADOW_SS_NEAR_BOUNDARY * shadowDistance;
bool traceable = nearRange ? (ndl > 0.0 && sssStrength <= 0.0)
                           : (ndl > 0.0 || sssStrength > 0.0);
if (traceable && max3(shadowVis) > SHADOW_SS_GATE) {
    float ssVis = screenSpaceShadowVisibility(viewPos, normalView, distWorld);
    float sssFade = sssStrength > 0.0
        ? remapSaturate(distWorld, SHADOW_SS_NEAR_BOUNDARY * shadowDistance,
                        SHADOW_SS_HANDOVER * shadowDistance, 0.0, 1.0)
        : 1.0;
    ssVis = mix(1.0, ssVis, sssFade * SHADOW_SS_STRENGTH);
    shadowVis = min(shadowVis, vec3(ssVis));
}
#endif
```

- **`ndl > 0` 用未 wrap 的原始余弦**：植被背光透光面（wrap 后 >0 但原始 <0）近景不 trace
  ——薄叶透光是本包植被观感的立身之本；远景参与 trace 但经 0.7→0.9D 渐入，透光观感在
  接管必要性（0.9D 外树冠必须有影）之前让位，过渡带内两者兼得（春v2 同款语义、窗位不同）。
- **`max3(shadowVis) > GATE`（0.01）**：彩色阴影 rgb 语义下取最大通道判「是否全影」——贴图
  已判死影处 trace 纯浪费（春v2 早退同款）；半影区照常 trace，min 合成下贴图 0.4 × SS 0
  仍是 0、不双重压暗——**这是选 min 不选乘的理由**（乘会把 PCF 半影与 SS 半影叠乘过暗）。
  D 外贴图可见性恒 1，门自然放行——接管区全部照常 trace。
- **彩色阴影兼容**：不透明遮挡者命中 → min 把 rgb 整体压 0（玻璃后另有不透明物 = 全影，
  正确）；玻璃自身不在 depthtex1、不参与 trace，其透射色阴影语义原样保留。
- **阴影贴图淡出窗（对 `sampleShadowVisibility` 的修改，接管无缝的前提）**：现行为 `dist >
  shadowDistance → return 1` 硬切，改为计算结果乘 `remapSaturate(dist, 0.9D, D, 1, 0)`——
  0.9D 内逐位不变、0.9D→D 淡出、D 外仍为 1。无此窗则 D 处贴图软影瞬间消失、SS（更噪）顶上，
  可见跳变；有此窗则「SS 在 0.9D 前已全程在场（min）→ 贴图淡出 → SS 独挑」连续交接（春v2
  同款）。晨昏黑过渡吸收该窗与主光源切换的一切交互（既有机制不变）。
- **D 外整体微减弱 ×0.9**（春v2 `remap(0.9D, D, 1.0, 0.9)`）：接管区 SS 噪声 / 肥影略减负的
  观感微调，默认**不采纳**（保持 1.0），常量 `SHADOW_SS_FAR_SCALE` 留旋钮。

### 2.5 与各系统的交互（全部免适配，逐条依据）

- **TAA**：结果乘进 shadowVis 进 colortex0，composite_taa 时间累积收敛抖动边缘——与 PCF
  temporal bayer 完全同族，无新机制。
- **TAAU**：trace 在渲染分辨率子区域域内进行（deferred_init 本就运行于子区域，gl_FragCoord
  即渲染纹素），bufUv 越出子区域读到的深度是引擎每帧清屏的 1.0（不伪命中）；随 TAAU 上采样
  由 composite_taa 解析，与云同款待遇。
- **雨天 / 昼夜切换**：SS 可见性乘在直射链路上，vDirectIrradiance 的雨天 ×0.25 与黑过渡
  自动联动，无需任何分支。
- **自动曝光**：远景接管把大片远处地形压进阴影 → 测光下移、曝光微升——与「远处从此有影」
  的画面变化同源，无特殊处理。
- **手部像素**：其 viewPos 重建本就带深度重映射误差（现有 shadeSurface 采样贴图同款近似），
  trace 照常参与、按实机验收；失真明显则以 NDC < TAA_HAND_DEPTH 一行整体跳过。

### 2.6 排除的备选

| 备选 | 排除理由 |
|---|---|
| 独立 composite pass + 半分辨率 R8 缓冲 | 直射 / 环境在 colortex0 已不可分离；多 pass 多缓冲违背低配定位与共性 #1 |
| Photon 式距离 fade **mix**（近贴图 / 远 SS 各算各再混合） | mix 语义下近景 SS 不再压暗贴图半影（接触细节损失）；贴图淡出 + min 的春v2 形态结构更简单、与本包 min 合成自洽 |
| BSL / Complementary 式 80~150 格超长 trace + LOD 深度链 | 本包无 DH / Voxy，主 depthtex1 已覆盖全部几何；min 形态下 SS 全程在场，10 格封顶 + 大厚度窗已覆盖山体尺度 |

| NDC / 屏幕域步进（Photon / Bliss / Kappa） | 厚度窗口世界单位语义更直接；每步投影 ALU 已由端点齐次插值场化（每步 4 mad、透视精确——齐次域插值不属于该行的「屏幕域插值」失真域） |
| absorption 软累积（Sundial） | 二值 + dither + TAA 已够软；留作扩展点 |

## 4. 性能

- 最坏每被 trace 像素 **+8 次 textureLod(depthtex1)** + 8×2 次 (mat4×v4 + rcp) 的 ALU（被
  fetch 延迟掩盖）。对照：受光几何像素现有 PCF 6~12 tap，阴影采样总成本约 ×1.5~2。
- 门控链：天空不进 shadeSurface → 背光非 SSS（直射本就为 0）→ 近景 SSS → 贴图全影。
  晴天户外约一半几何像素付全款（含全部接管区——D 外贴图可见性恒 1、门放行）；室内 / 夜晚
  几乎零像素 trace。
- TAAU S=0.7 下像素成本 ×0.49，与全管线一致。
- 1080p 原生档粗估：~40~50% 屏幕像素 × 8 fetch ≈ 3.3~4.2M 深度 fetch / 帧，约等于 PCF 低档
  tap 总量的六到八成——低配可接受档；极限档降 `SHADOW_SS_STEPS = 6`。

## 5. 已知限制（屏幕空间固有，全部记入 AGENTS 已知限制）

- **屏外遮挡者不可见**：屏幕边缘 / 刚出画的几何漏投（近景贴图兜底只丢接触细节；**接管区
  无兜底**，远处遮挡者出屏即漏影——屏幕空间接管的固有上限，BSL/Complementary 同样受制）。
- **接管区噪声 / 肥影**：20 格大窗 + 8 步稀疏采样下，远景阴影是「统计上正确」的软影，个别
  帧个别像素有肥影 / 拖影闪烁，TAA 时间累积收敛；嫌粗降 LENGTH_FAR / 用 FAR_SCALE = 0.9。
- **掠射光下竖直薄片**（栅栏等小几何）：3D 距离窗对「射线水平绕过薄遮挡者」比深度窗 robust，
  但薄片厚度 < 步距时仍漏——接管区小几何本就贴图兜底（0.9D 内），只在窗外暴露。
- **粒子不投接触影**（depthtex1 不含）；换来运动半透明几何不产生闪烁伪影。
- **手部 texel 不作遮挡者**（深度重映射失真）；手部像素自身照常被 trace。
- **交接带观感**：0.9D→D 贴图淡出与 SS 渐主导并存，若该距离带贴图软影与 SS 噪声影风格差
  异可见，微调 HANDOVER 窗位（唯一相关旋钮）。
- **与未决问题「移动时暗处棱边白点闪烁」的交互**：本效果恰在棱边接触带新增屏幕空间噪声，
  落地排期应在该问题排查结论之后，或同帧 A/B 确认不引入回归（AGENTS 已知限制条）。

扩展点（按优先级）：absorption 软累积模型；trace 长度 / 厚度按材质分档（iterationRP 草 /
叶专用长度思路，可复用 colortex4 标记通道）；粒子遮挡（换 depthtex0 一行开关）；接管区
blocker depth 输出喂 SSS（Bliss 思路）。

## 8. 修订补记（2026-09）：步内 ALU 场化

低配定位推动的代数等价重写（float64 数值验证机器精度级等价、命中谓词 64000+ 组零翻转、
w≤0 break 判定零翻转）：

- **端点齐次插值替代每步矩阵乘**：初版否决「两端点插值」时把它与 NDC/屏幕域步进归为同一
  失真域——实际失真只发生在对透视除法**之后**的 uv/NDC 插值；对除法之前的 clip 4 维向量
  插值（矩阵乘对齐次坐标线性）与逐点投影代数恒等。两端点 `P·(o,1)` / `P·(stepVec,0)`
  出循环，每步 16 mul + 12 add → 4 mad。
- **视锥常数闭式重建场景点**：§2.3 预留的「正向投影系数解析线性深度」后路的执行——
  `gbufferProjection` 恒为典则对称透视矩阵（OptiFine / Iris 注入），`viewZ = −d/(ndcZ+c)`
  （1 次除）+ `view.xy = ndc.xy·(1/a,1/b)·(−viewZ)`，免每步第二次 mat4 + 3 div。
- **距离窗平方比较**：`dot(scene−p, scene−p) < thickness²` 与 `distance < thickness`
  同谓词，免每步 sqrt（thickness² 出循环预算）。
- **uv→buffer 域折叠 + jitter 外提**：applyJitter 仿射（uv·S + jitter），系数经两端点
  `applyJitter(0)` / `applyJitter(1)` 反解——唯一真源保持（TAAU 语义变更自动跟进），
  taaJitterUV 的常量表动态索引随之出循环。
- **渲染边界淡出带终点早退（当日回退）**：`dist ≥ EDGE_END·far` 提前 return 1.0 只与
  miss 路径的尾部 mix 恒等——但命中在循环内直接 return、不经尾部 fade，且 FAR_SCALE 默认
  1 下 miss 尾部整段恒等，**远场（贴图覆盖外）接管影全部来自命中返回**；早退把真实命中与
  噪声命中一并砍掉，实测远景接管影消失（视距小时 EE·far < D、接管带整片归零），当日回退。
  教训：淡出只作用 miss 路径是隐式契约，「边界带回退无影」仅对 miss 成立。

合计每步 2 mat4 + 5 div + 1 sqrt → ~20 mad + 2 div（ALU ~3× 削减），两个依赖 fetch 之间的
ALU 链显著缩短（低配卡 warp 在途少、该链原本暴露）。`screenToView` 依赖自 shadow.glsl
移除（space.glsl 本体不动，TAA / deferred_init 继续用）。
