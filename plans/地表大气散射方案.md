# 地表大气散射方案（设计稿，260929）

> 定位约束：低配 / 高兼容、不引入激进渲染特性。结论：**「表面 × 路径透射率 + 路径内散射」的
> 物理式空气透视（aerial perspective），经一张小 LUT 供给**——生成端直接复用 atmosphere.glsl 的
> Chapman 解析核心（`atmosphericRadianceSingle` 原生支持有限路径长度 t，含 tauSp 端点几何，
> **零数学改动**，唯一缺口是 `out` 一条路径透射率）、挂在 composite12 现有的天空 LUT 重算 pass
> 里（vsh 帧常量 observerRadius / horizon / 日月方向 / tauS / ambientField 已全部就位）；消费端
> 落在 composite_fog（composite2），与边界雾同一套 depthtex0 距离 / 去抖重建 / 帧数据 varying。
> **零新 pass、零新缓冲、零纹理资产**：LUT 放 colortex7 的 256×256 天空盒预留区（左下 64×192，
> 该区域至今空置）。生成 ≈ +0.3~0.6% 屏幕成本（天空 LUT 现有 ~2% 的三成以内），采样端远几何
> 像素 +2 fetch + ~20 ALU、近距与天空像素零成本。

---

## 0. 需求与「mix 一个颜色」直觉的定位

用户直觉「类似边界雾那样 mix 一个颜色」方向正确，本方案是它的严格化。物理式为：

```
finalColor = surfaceColor × T(viewDir, dist) + S(viewDir, dist)
```

- `S` = 相机→表面路径上大气再散射进视线的光（inscatter，加光项）；
- `T` = 同一路径的透射率（表颜色的衰减项）。

**均匀介质下两式严格等价**：`S = A × (1 − T)`（A = 该方向饱和雾色）时
`mix(A, surface, T) ≡ A(1−T) + surface×T`。解析大气里 S 与 T 不严格共因子（路径端点沿光源
方向的消光 tauS/tauSp 参与加权，见 `energyIntegralRatio`），加法式不比 mix 贵、且无近似损失。
观感上仍是「远处 mix 向天光色」，但雾色随**方向 × 距离 × 时刻**连续变化：逆光发白（Mie 前向
峰）、顺光偏蓝、抬头散去、日落时山下暗山上亮（路径末端进入地球阴影）——这些正是边界雾已知
限制清单里「无光照方向性、无高度衰减体积感」要补的东西。

## 1. 前提核实（已对代码确认）

- `atmosphericRadianceSingle(origin, direction, phaseDirection, lightDirection,
  lightOpticalDepth, t, irradiance, out viewCapture)` 的 `t` 参数本就是「视线行星命中距离
  （SKY_NO_HIT = 朝天）」——**有限路径即相机→表面的积分**，`tauSp`（路径终点沿光源方向到
  大气顶的消光）的 `if (t < 1e29)` 分支现成。天空 LUT 只用了 `t = NO_HIT` / 命中两种值，
  aerial 传 `t = 等效路径距离` 即可，函数体一字不改。
- 透射率缺口：视线路径总消光 `tauV = rayleighView + mieView×1.11 + ozoneView` 在函数内部
  已算（第 186 行），只是没导出。**唯一数学改动** = 加 `out vec3 viewTransmittance = exp(-tauV)`
  （`atmosphericRadiance` 同步透传），exp 是原有 `ambientCapture` 里已有的一次 exp 的复用
  代价级别、零结构性变化。
- composite12（composite_bloom_upsample `BLOOM_LEVEL == 0`）vsh 已预计算并经 varying 传入：
  observerRadius、horizon 几何、日月世界方向、日月 opticalDepth、日月 ambientField——aerial
  生成端全部直用，**vsh 零新增**。
- composite_fog 已有：depthtex0 全几何距离（含水 / 手 / 粒子）、去抖 uv 基底 + 典则闭式重建、
  世界方向归一、vSunDirection / vMoonDirection / vHorizon / vSkyLutValid 帧数据——**消费端
  只加混合式本身**。

## 2. 关键障碍与三条不变式

### 2.1 MC 视距内真实大气几乎不可见（量级估算）

水平 500 m 路径的等效垂直气团 ≈ 500/8500，绿光 Rayleigh 光学深度 ≈ 12e-6 × 500 ≈ 0.006 →
inscatter ≈ 0.6% 天空亮度——物理参数直用则 far=512 格内**看不到任何雾**。必须艺术放大。
而且水平路径的海平面密度段极长（几何爬升 s²/2R 在百 km 尺度才压密度）：inscatter 渐近到天空
色需要数百 km 等效路径，28.6 km（64 m 海拔的地平线切线距离）处仅 ~30% 融合度。两个推论：

1. 观感强度必须靠一个「等效距离放大」旋钮，缺省量级几十~几百；
2. **far 端的硬融接不可能由物理路径独立完成**（融合度上限低）——边界雾保留、继续兜
   0.7~0.9·far 的渲染边界融接，aerial 管中近距物理空气感。**两段式，不是替代关系**。

### 2.2 不变式一：放大距离、不放大密度（渐近 = 天空色）

`inscatter(∞)` 由球对称大气与起点完全决定；把路径长度乘 SCALE 不改变极限值、只改变到达
速度。若改放大密度 / 标高，无穷远 inscatter 变成「浓版天空」≠ 屏幕 sky-view LUT 值 → 地平线
处地形与天空色差缝（边界雾「钳制深度必须与 LUT 饱和深度重合」三代教训的同族问题）。**因此
SCALE 是纯距离域旋钮**；雨天加浓同样走距离域乘子 `(1 + AERIAL_RAIN_BOOST × rainStrength)`
（密度域调制同理破坏渐近，禁用）。

### 2.3 不变式二：∞ 档 ≡ sky-view LUT（结构性融接）

LUT 距离维第 4 档直接存 `t = SKY_NO_HIT` 的求值 = 同参数 atmosphericRadiance × SKY_BRIGHTNESS
= sky LUT 同方向的值（同 observerRadius / tauS / ambientField / 双光源，参数化插值差内）。
远端融接不再靠「把雾色调成天空色」的约定，而是**布局结构保证**——这是边界雾手工伪造
（雾色取 LUT 切线行）的物理版本。

### 2.4 不变式三：天空像素不施加

渐近一致性只在几何侧成立（天空像素 = LUT + 太阳盘 + 云的最终合成，山后没有太阳盘加成本就
正确）。depth ≥ 1 像素跳过整个 aerial 段，零成本、零 double-scatter。

### 2.5 下视行为与数值防护（SCALE 的固有失真）

等效路径是「沿视线方向走 t_eff 米」，其虚拟终点半径 `rP = sqrt(t² + 2zrt + r²)` 在下视远距
时会低于 EARTH_RADIUS（虚拟钻地）。防护：生成端 `rP = max(rP, EARTH_RADIUS)`（终点钳贴地，
airMass 内的 SKY_ERFCX_EXP_MAX / SKY_AIRMASS_MAX 防护本就兜住数值）。**不截断 t**（截断到
planetHitDistance 会让俯视远处整段无雾——MC 常见视角，不可接受）。定性结果反而正确：

- 正午俯视远处：tauV 巨 → trans→0、inscatter→饱和贴地气团色 → 俯瞰远处浓雾 ✓
- 日落俯视远处：钳贴地的端点 tauSp 巨 → scatter 项趋 0 → 山下雾暗、山上雾亮（路径末端进入
  地球阴影）——aerial perspective 的招牌分层，白拿 ✓
- 夜间俯视远处偏暗：夜空本黑、黑融黑，且边界雾在远端以 LUT 切线辉光色兜底 ✓

## 3. 为什么是 LUT（而不是逐像素解析 / raymarch）

- **逐像素解析**：全屏每像素一次 atmosphericRadiance ≈ 天空 LUT 总成本（80k texel ≈ 2%
  屏幕成本）× (2M/80k) ≈ **~50% 屏幕成本的纯 ALU**——composite2 从最轻 pass 变最重之一，
  低配定位直接排除。留作 `AERIAL_ANALYTIC` 调试对拍档（不进默认档）。
- **raymarch / 体积雾**（BSL / Complementary 路线）：步进 + 密度采样 + 阴影遮挡查询，成本
  与复杂度均不符定位；且本包已有闭式解析核心，march 是降级。
- **LUT**（Hillaire 2020 的 aerial LUT 思想同源）：他按「视角 × 距离 × 海拔 × 光谱」4D、
  每帧 raymarch 生成；本包地面玩家海拔近似恒定砍一维、Chapman 解析生成砍 march——LUT 是
  思想参考，生成端是自家 sky 基建的延伸，无实现重叠。
- 消费端比解析便宜两个数量级：方向双线性（textureLod 0）× 相邻两档 + 线性 lerp = **2 fetch**。

## 4. LUT 设计

### 4.1 布局（colortex7 天空盒预留区，缓冲归一化坐标）

```
原点 (0, 0)（缓冲左下角），区域 64×192 texel = 方向 64(方位) × 48(天顶) × 4 距离档纵向堆叠
与既有槽位无冲突：曝光 (258,0) / 标记 (259,0) / sky-view x ∈ [260, 460) 均在 x ≥ 258，x ∈ [0,64) 不重叠
预留区剩余（x ∈ [64,256) 全高 + (0~64)×(192~256)）继续留给未来天空盒探针
bloomMiscRectMax() 扩为并集包围 → composite12 光栅包围盒从 ~(258,0)~(460,200) 扩到 (0,0)~(460,200)，
透传 read-back 增量 ≈ 0.1% 屏幕，可忽略
```

常量：`AERIAL_LUT_W = 64`、`AERIAL_LUT_H = 48`（方向分辨率，低于 sky-view 的 200×100——aerial
是低频量、被距离维插值与 TAA 时间累积双重平滑，Mie 前向峰在 sqrt 参数化下光源侧 ~13 texel、
bilinear + TAA 足够）、`AERIAL_LUT_SLICES = 4`。RGBA16F：rgb = inscatter（含 MS 项、已乘
SKY_BRIGHTNESS）、a = 透射率标量（取绿通道 550 nm——chromatic 透射为扩展点，见 §10）。

### 4.2 方向参数化（复用 sky-view 互逆组，单真源）

天顶参数 `skyViewLutZenithParam`（双段 sqrt 向地平线集中）、方位参数 `skyViewLutAzimuthParam`
（sqrt 向光源侧集中）**公式照抄、分辨率独立**；生成端逆映射同 `skyViewLutTexel` 的局部系
构造（「光源水平投影 = +X、光源位于 XY 平面内」，球对称等价）。方位锚 = 主导光源：
`sunDir.y > SKY_LIGHT_MIN_HEIGHT ? sun : moon`——与半区写黑同一门控（SKY_LIGHT_MIN_HEIGHT =
−0.15，日月恰好相对时主导权交接发生在黑过渡窗内、双光源贡献均趋零，参数化重排不可见）。

**双光源和式、不分半区**：散射积分对光源线性，LUT 直接存 sun + moon 之和（各光源低于
SKY_LIGHT_MIN_HEIGHT 时跳过求值——与天空 LUT 非活动半区写黑同一纪律，多数时间单光源，
生成成本减半）。

### 4.3 距离档与插值域

档位（等效米）：`{1024, 4096, 16384, ∞}`，**存储按 log 档、插值按线性距离权重**——
inscatter 在未饱和段近似线性于 t，log 域 lerp 在档间中点有 ~25% 系统性偏差（真实值 0.4×上限
vs 插值 0.5×），线性权重两行代码消掉。采样端：

```
t_eff = distWorld × AERIAL_DIST_SCALE × (1 + AERIAL_RAIN_BOOST × rainStrength)
t_eff < 档0 → 早退（近距零成本；inscatter < 档0 值的一半 ≈ 1~2% 天空亮度，低于可见阈）
t_eff > 档2 → 用 ∞ 档（不再增长——渐近不变式）
否则 w = (t_eff − t_i)/(t_{i+1} − t_i)，result = lerp(LUT_i, LUT_{i+1}, w)
```

档内天顶维边界半纹素内缩（`lutParamToTexelCenter` 同款纪律，防跨档条带串色——相邻 texel
是同方向不同距离）。

### 4.4 生成端（composite12 fsh 加一个区域分支）

```
local.x ∈ [0,64) 方位、local.y ∈ [0,192)：天顶行 = local.y % 48、档 = local.y / 48
方向反参数化 → dirWorld（局部系）；t_d = 档位距离（∞ 档传 SKY_NO_HIT）
每档每 texel：
  t = t_d；对日光 + 月光各调 atmosphericRadiance(origin, dirWorld, dirWorld, lightDir,
      tauS, t, irradiance, ambientField)（MS 含在内，∞ 档与 sky LUT 同构）
  rP 钳制在 atmosphericRadianceSingle 内部 tauSp 段做（max(rP, EARTH_RADIUS)）
  a 通道 = exp(-tauV) 绿通道（经新 out 参数带回）
  × SKY_BRIGHTNESS 写出
```

有效性 / 滞后一帧与 sky LUT 同源同批（同 pass 写入、`vSkyLutValid` 共用、composite12 帧末
生成下帧 composite2 消费——sky 先例：无视觉差异）。`AERIAL_PERSPECTIVE` 宏关时该区域落入
「其余透传」分支，保值无害。

### 4.5 采样端（新 lib `lib/atmosphere/aerial.glsl`）

`sampleAerialLut(dirWorld, tEff, anchorLightDir, horizon)` → vec4(inscatter, trans)；
`applyAerialPerspective(inout color, ...)` 总入口（早退链：水下 → 近距；天空像素由调用方
分支在外）。采样 uv 可选加 TAA jitter 亚像素偏移（sky LUT 同款，平滑 facets——低配可不做，
一句话开关）。主导光源判定在 fsh 一次 select（或 vsh flat varying 预算，实现时定）。

## 5. 接入：composite_fog 消费端与两段式

composite_fog 几何分支，在 `applyBoundaryFog` **之前**：

```glsl
vec3 dirWorld = ...;               // 已有（边界雾共用同一次归一）
float distWorld = length(viewPos); // 已有
vec4 aerial = sampleAerialLut(dirWorld, distWorld * AERIAL_DIST_SCALE * rainMul, ...);
color = color * aerial.a + aerial.rgb;
applyBoundaryFog(color, viewPos, skyPixel, ...);  // 照旧
```

- 早退链合并：水下 → 近距（t_eff < 档0 且边界雾未起 → 整像素 return，屏幕大多数像素全免）。
- 两段职责：aerial = 中近距物理空气感（方向性 / 色彩 / 高度衰减 / 曙暮光分层），boundary =
  far 端渲染边界硬融接兜底。0.7~0.9·far 带两系统叠加（double-dip 的风格化取舍，见 §8 调参
  联动）。
- `AERIAL_PERSPECTIVE` 删宏 = aerial 段编译剔除、逐位回退现状（边界雾独立）；两宏全关 =
  现有透传旁路。开关 / 数值分离纪律同 TAAU / RCAS。

## 9. 风险与开放问题

- **锚光源切换重排**：主导权交接（sun.y 过 −0.15）时方位参数化整体重排。内容连续（同物理）、
  时机在黑过渡窗内、TAA 吸收——理论不可见，实机确认一次。
- **标量透射率丢色散**：日落远山「表面红化」（Rayleigh 蓝通道衰减快）不呈现；inscatter 侧的
  色彩（蓝霭 / 红日方向）完整。扩展点 §10。
- **4 档 × 线性插值的中距误差**：凸函数两档线性内插误差 ≤ 半档斜率差，低频量 + TAA 下预计
  不可见；嫌可见升 8 档（§8）。
- **下视远距的失真带**：等效路径虚拟钻地由 rP 钳贴地防护（§2.5），定性正确但定量粗糙；远端
  有边界雾兜底。
- **远端 double-dip**：aerial + boundary 在 0.7·far 外叠加，物理上重复计入散射——风格化取舍
  （boundary 本就是融接工具而非物理雾），调参联动 §8。
- **composite12 fsh 编译体积**：+1 分支 + aerial.glsl include，编译时间微增。
- **月夜极淡**：月光辐照度 = 太阳 / 2000，夜雾几乎不可见（物理）。统调走 `MOON_IRRADIANCE`

- **首帧 / 缓冲重建**：读到垃圾值乱一帧，`vSkyLutValid` 同源回退 + TAA 吸收（sky 同款）。
- §2.1 的 airMass / 融合度为量级心算，实施标定以实机为准（SCALE 缺省 64 只是起点）。

## 10. 扩展点

- **chromatic 透射率**：预留区再划一条 64×192 存 rgb 透射率（或 a 通道改存 tau 的双色近似），
  采样 +1~2 fetch——日落远山红化补全。
- **`AERIAL_ANALYTIC` 调试档**：逐像素直调 atmosphericRadiance（无 LUT 插值），对拍 LUT 精度
  用，不进默认档（成本见 §3）。
- **水面反射 / 云影同源复用**：`sampleAerialLut` 按方向 + 距离参数化，反射视线以反射路径
  距离调用即可；云海拔处的 aerial 用 vCloudTransmittance 同族思路另接。
- **高度雾化风格档**：观察者海拔大时（飞行）aerial 随高度自然稀薄（Chapman 起点半径参与，
  生成端已正确）；若嫌高空过浓再议海拔补偿旋钮。
- **与边界雾的统一**：若实测 aerial + SCALE 调大后 far 端融合度足够（SCALE ≥ 256 时 far=512
  → 128 km 等效、inscatter 融合度 ~70%+），可评估收窄或移除 boundary fog——独立开关已保证
  可分步回退，不急于此。
