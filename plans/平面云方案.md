> **实现状态（260909，第二次修订）**：本文的自研方案（球壳 slab 弦长 Beer + 伪自阴影 + 银边
> pow）首版落地后实机观感不佳，按反馈**整体替换为春v2 clouds2D 方案的移植**（2D 云原作者
> Coldnight冷夜）——云壳求交 / 角坐标 / 6 octave simplex fbm 差速演变 / KN 前向散射相位 /
> alpha = 密度 × 距离衰减；归属与本包适配点（世界锚定、雨天 coverage、帧数据供光、亮度重定标）
> 见 AGENTS.md「云」条与 clouds.glsl 头注。管线接入两版一致（deferred_init 天空分支预乘合成、
> vCloudTransmittance varying、CLOUDS_2D 开关宏）。本文余下内容为首版调研与设计依据存档，

> 定义在 constants.glsl 引入之前被判假）、常量改名后的悬空引用（CLOUD_ALTITUDE →
> CLOUDS_2D_HEIGHT 漏改 fullscreen_vsh，deferred.vsh 编译报错后修复并给静态校验补了旧符号归零检查）。
> 后续追加（260910）：本文 §5 的**伪自阴影**在春v2 移植版上重新落地——`cloudDensityAt` 同一
> 密度场朝光源水平方向偏移 `CLOUDS_2D_LIGHT_DRIFT` 米重采样求差，经 `SHADOW_GAIN / SHADOW_STRENGTH`
> 调制直射项（±35% 的一层淡阴影，SEUS 同思路）；另按反馈把晴天覆盖率上调至 0.55。

> 定位约束：低配 / 高兼容、不引入激进渲染特性。结论：**单层解析平面云**——球壳求交 +
> 单次噪声形状求值 + 全部光照复用现有帧数据 varying，画在 `deferred_init` 天空分支（TAA 之前）。

## 2. 总体设计决策

### 2.1 为什么是「单层单次求值」而不是别的

- **多层薄平面（BSL 式）**：厚度感来自 10 层采样，成本 ×10。我们用 Kappa 的弦长 Beer-Lambert
  从「单次求值」里解析挤出厚度梯度（掠射角浓、天顶薄），观感覆盖七八成。
- **raymarch（Kappa/Photon/Bliss）**：与定位冲突，排除。
- **烘进 sky-view LUT**：LUT 是纯方向函数、无相机位置自由度；云在有限高度、有平移视差
  （走两步 / 飞行就穿帮），且会污染 `vSkyAmbient` 探针。排除，云只在主画面解析。

### 2.2 画在哪：`deferred_init` 天空分支（deferred 阶段）

- **时序关键**：天空在本 pass 进 colortex0 的同款理由——之后的前向半透明（水 / 玻璃）引擎混合
  才有正确的「透过云」背景；画在 composite 则水面叠天空处混到无云底色。
- **TAA 之前**：噪声 dither / 形状边缘抖动由 composite_taa 时间累积免费抹平（BSL/SEUS/c13 同款）。
- **TAAU 顺带**：deferred_init quad 已缩进渲染子区域，云只花 ×S² 的像素成本，composite_taa
  上采样对云与对天空同路径、零适配。
- **遮挡天然正确**：只有 `depthtex1 ≥ 1` 的天空像素画云 → 地形自动在云前；粒子深度在
  depthtex0 不在 depthtex1，不会被云错误遮挡（与天空判定同一纪律）。

### 2.3 光照零新增计算：全部来自帧数据 varying

云的光色 = `vDirectIrradiance × vCloudTransmittance`（新 varying）+ `vSkyAmbient`。昼夜切换
黑过渡（noon/night 门）、雨天直射 ×0.25、雨天环境去饱和——全部由现有 varying 自动带给云，
与地形 / 天空同源同帧，不需要为云单独算任何大气量。**唯一新增**：`vCloudTransmittance`
（云高度处的主光源透射率）——在通用全屏 vsh 里用现成的 `opticalDepthToSpace(EARTH_RADIUS
+ CLOUD_ALTITUDE, vLightDirection.y)` 多算一行（每帧 3~4 顶点一次，零像素成本），日落时
云比地面更晚变红（高处透射率高），物理方向正确、观感是「红云」。

### 2.4 噪声：纯 ALU（零资产）

项目至今零纹理资产、TAA jitter 是查表纯 GLSL——延续。加 value noise + fbm 到
`lib/common/utils/noise.glsl`（项目噪声库之家）。约 8 次求值 × ~25 ALU ≈ 200 ALU/天空像素，
低配 GPU 完全可承受（对照：BSL ~20+ 次纹理 fetch、SEUS ~12-16 次）。hash 用无 sin 的浮点
hash（iq/pcg 风格），规避春v2 sin-dot 在大坐标下的精度风险。接口按「可换 noisetex」设计
（若未来实测 ALU 吃紧，函数内部换纹理采样、调用方零改动）。

## 3. 几何设计

球壳模型（与 `atmosphere.glsl` 共用 `EARTH_RADIUS` 常量——云的地平线下坠与大气曲率一致）：

```
云壳半径 R_c = EARTH_RADIUS + CLOUD_ALTITUDE          // 单层 slab：[R_c − D/2, R_c + D/2]
o = (0, EARTH_RADIUS + cameraPosition.y, 0)           // 相机在行星坐标系
对底壳 / 顶壳各解一次 ray-sphere：t_bottom, t_top（取 near 根）

t_entry = min(t_bottom, t_top)    // 仰视 = 云底入射；俯视（相机在云上）= 云顶入射，统一处理
t_exit  = max(t_bottom, t_top)
chord   = min(t_exit − t_entry, CLOUD_CHORD_MAX)      // slab 内弦长；上限防掠射角爆炸
worldXZ = cameraPosition.xz + dirWorld.xz * t_entry   // 世界锚定（相机平移云不动）
```

- **下视角 / 高空俯视**：相机在云上方时 entry 落在顶壳（俯瞰云海），同一套公式，无需分支
  （春v2 同思路，Kappa 用 `IsPlanet` 门控解决同款问题）。
- **地平线带**：与云壳相切以下的射线无交点 → rsi 无解 → 自然无云；再往下的射线先撞行星
  → 由天空像素判定（depthtex1）挡掉。**不需要 BSL 式仰角门限补丁**，边界由几何 + 距离衰减收口。
- **距离衰减**：`fade = exp(-max(t_entry - CLOUD_FADE_START, 0) / CLOUD_FADE_LENGTH)`，
  最终 `alpha *= fade`。地平线附近（射线近水平 → t 巨大）云完全溶进大气 LUT 的地平线亮带。
- **风**：`worldXZ += CLOUD_WIND_DIR * (CLOUD_WIND_SPEED * frameTimeCounter)`（真实平移，
  世界锚定）；fbm 各 octave 速度 ×(1 + 0.1·i)（春v2 差速演变：云形自己缓慢变形）。

## 4. 形状（噪声与覆盖率）

```
p = worldXZ / CLOUD_NOISE_SCALE                        // 一团云 ~几百米至千米
p /= 1.0 + t_entry * CLOUD_DETAIL_FADE_K               // Kappa 距离压缩：远处频率压低防闪烁
p += valueNoise2D(p * 0.5) 的低频 warp * CLOUD_WARP    // 1 次 domain warp 打碎重复感

n  = fbm2D(p, 4 octave, octave 间 2×2 旋转去轴对齐)     // 4 次求值
cov = mix(CLOUD_COVERAGE_CLEAR, CLOUD_COVERAGE_RAIN, rainStrength)
d  = smoothstep(1.0 - cov, 1.0 - cov + CLOUD_EDGE_SOFT, n)   // 标准覆盖率重映射（自写实现）
d  = smoothstep(0, 1, d)²                               // 边缘再锐化一次（春v2 二次 smoothstep 同效）
d += (temporalBayer64(gl_FragCoord.xy) - 0.5) * CLOUD_DITHER   // 时域 dither，TAA 收敛（阴影 PCF 同款纪律）

alpha = 1.0 - exp(-d * CLOUD_EXTINCTION * chord)       // Kappa 弦长 Beer-Lambert：地平线浓、天顶薄
alpha *= fade
```

雨天：coverage 抬到阴天值 + （可选）密度乘子；直射 / 环境的雨天衰减已由 varying 带来。

## 5. 光照

```
direct = vDirectIrradiance * vCloudTransmittance                // 云高处直射（vsh 一行，见 2.3）
sd  = d - d(p + lightDir.xz * CLOUD_SUNDRIFT)                   // SEUS 伪自阴影：沿太阳方向偏移
                                                                //   重采样一次（2 octave 降配版），差→朝光面亮
ph  = pow(saturate(dot(dirWorld, vLightDirection)), CLOUD_SILVER_POW)   // 银边：前向散射 pow 近似
silver = ph * (1.0 - alpha) * CLOUD_SILVER_STR                  // 薄处（低 alpha）银边最强

scatter = direct * (0.6 + 0.8 * saturate(sd * CLOUD_SUNDRIFT_GAIN))     // 朝阳面亮、背阴面暗
        * (1.0 + silver)
        + vSkyAmbient * CLOUD_AMBIENT_SCALE                                // 环境项（昼夜/雨天自动）
scatter *= CLOUD_BRIGHTNESS                                    // HDR 幅度对齐天空/地形量级（曝光域）
```

- 银边先用 pow 近似（BSL `pow(VoL,6)` 同级成本）；双瓣 HG 升级为可选项。
- 夜晚：vDirectIrradiance 已切月亮辐照度（×5e-4）→ 月光云、晨昏黑过渡全部免费。
- vSkyAmbient 探针来自晴空 LUT——云不反向影响环境光（BSL 同款取舍），见扩展点。

## 6. 合成

deferred_init 天空分支（getSkyColor 之后两行）：

```
vec4 cloud = getPlanarClouds(...);            // rgb = 散射（预乘域），a = 透射率
color = cloud.rgb + color * cloud.a;          // premultiplied 前向合成
```

- 地形像素（depthtex1 < 1）不画云：遮挡正确。
- 云不写深度：TAA 把云当天空处理（`TAA_DEPTH_SENTINEL` 路径），重投影用纯旋转链——正确，
  因为云近似无穷远方向场；云的平移视差由当前帧重新求值 + 方差钳制收敛。
- **已知取舍**：TAAU 档天空像素（含云）当前帧上采样降 bilinear → 云形状边缘经上采样略软
  （S=0.7 轻度）。与「柔和春云」观感相容；若日后嫌糊，评估在 composite_taa 提高该档锐度，
  不为此增加通道。

## 9. 实施分期

- **M1 形状上线**：uniforms / 常量 / noise.glsl / clouds.glsl 骨架 + deferred_init 合成；
  光照先用 `direct + ambient` 平光。验收：地平线无穿帮（掠射 / 下视角 / 云上飞行）、
  TAAU 开关两档、S=0.5/0.7 下无边缘异常。
- **M2 光照完整**：sundiff 伪自阴影 + 银边 + `vCloudTransmittance`（日落红云）+ 夜景 /
  晨昏过渡验证（noon/night 门黑过渡对云同样生效）。
- **M3 天气与打磨**：雨天 coverage / 密度 + 时域 dither + 常量调优 + 性能核对
  （天顶 / 地平线像素最坏路径）。
- **M4 扩展点（不阻塞交付）**，按价值排序：
  1. **云影**：Kappa/Photon 同款单点解析投影——lit 地形像素沿 `vLightDirection` 抬到云壳
     entry 处采一次同款密度（3~4 次噪声求值），乘进 shadeSurface 直接光；`#define` 门控。
  2. **环境耦合**：coverage 标量调制 vSkyAmbient（阴天环境变暗变平）。
  3. **水面 / 反射复用**：`getPlanarClouds` 以反射光线调用（函数按方向参数化，天然可复用）。
  4. 第二层高速卷云（ridged 噪声、更高壳、独立常量组）。
  5. 日月盘（将来画时）透射率乘云 alpha。

## 10. 性能预算

- 触发面：仅天空像素（1080p 约 25~45%），TAAU S=0.7 再 ×0.49。
- 每像素：2 次球壳求交 ~20 ALU + 噪声 8 次求值（warp 1 + fbm 4 + sundrift 2~3 + dither 表）
  ~200 ALU + 光照合成 ~30 ALU ≈ **250 ALU、0 fetch、0 pass**。
- 对照：BSL ~10 层 × 2~3 fetch（20+ fetch）；SEUS 12~16 fetch。实测量级低于两者。
- 若实测超预算的降级阶梯：fbm 4→3 octave → sundrift 3→2 →（最后手段）valueNoise2D 内部
  换 noisetex 采样（接口不变）。

## 11. 已知取舍（登记进 AGENTS.md「已知限制」）

- 云是解析单层：无真正的垂直结构 / 自阴影 march（sundiff 是伪 3D，背光透光感弱于体积云——
  定位内取舍，与 SEUS 同级）。
